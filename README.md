# wanoo.github.io

Redirects only. GitHub does not redirect a project's Pages after a repository is renamed or transferred.

- `wanoo.github.io/quest-n-click/…` and `wanoo.github.io/web-scumm/…` go to [Quest'n'Click](https://quest-n-click.github.io/),
  now in the [Quest-n-Click organization](https://github.com/Quest-n-Click): `/docs/…` to its `/docs/…`, everything
  else (the game, `studio.html`) to `/play/…`.
- `quest-n-click/sw.js` and `web-scumm/sw.js` replace the retired apps' service workers once, unregister, and reload.
